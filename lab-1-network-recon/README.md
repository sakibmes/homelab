# Lab 1: Home Network Reconnaissance

Active reconnaissance of my home network using Nmap to identify live hosts, open ports, and running services.

## Overview
- Built a headless homelab on a Dell OptiPlex, accessed via RDP
- Deployed a Kali Linux VM in VirtualBox
- Diagnosed and fixed a VM networking issue (NAT vs. Bridged mode)
- Ran Nmap host discovery and service/version scans, identifying 11 live devices
- Compared exposed ports across devices (e.g. PS5 vs. Google Home Mini)

## Tools
Kali Linux, Nmap, VirtualBox

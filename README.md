# Cybersecurity Homelab

A collection of hands-on homelab projects documenting my progression in cybersecurity, from network reconnaissance and exploitation to virtualization and Active Directory administration.

Full write-ups for each project are published on [Medium](https://medium.com/@mes.sakib).

## Projects

### 1. Home Network Reconnaissance
Active reconnaissance of a home network using Nmap — host discovery, service/version scanning, and port analysis.
**Tools:** Kali Linux, Nmap, VirtualBox

### 2. Metasploitable Exploitation
Exploited known vulnerabilities (vsftpd backdoor, Telnet credential capture, Samba usermap_script) to gain root access on an isolated lab network.
**Tools:** Kali Linux, Metasploit, Wireshark

### 3. Proxmox Homelab
Converted a used Dell OptiPlex into a Type 1 hypervisor running Proxmox VE, managed headless.
**Tools:** Proxmox VE, Linux CLI, virtualization

### 4. Active Directory Lab
Built a Windows domain (domain controller, client, OUs, users, groups), enforced Group Policy, automated user creation with PowerShell, and configured an account lockout policy.
**Tools:** Windows Server 2022, Active Directory, Group Policy, PowerShell

## Skills Demonstrated
Network scanning • Vulnerability exploitation • Virtualization • Active Directory • Group Policy • PowerShell scripting • Linux CLI • RBAC & least privilege • Technical documentation

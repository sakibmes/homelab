# Lab 4: Active Directory Lab

Built a Windows domain from scratch on the Proxmox homelab to simulate a corporate identity environment.

## Overview
- Deployed a Windows Server 2022 domain controller (sakiblab.local)
- Joined a Windows 11 Enterprise client to the domain
- Created OUs, users, and security groups applying RBAC and least privilege
- Enforced restrictions via Group Policy (GPO)
- Automated bulk user creation with a PowerShell script (New-ADUser)
- Configured an Account Lockout Policy to mitigate brute-force attacks

## Tools
Windows Server 2022, Active Directory, Group Policy, PowerShell

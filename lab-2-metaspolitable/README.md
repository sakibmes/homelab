# Lab 2: Metasploitable Exploitation

Exploited known vulnerabilities on an intentionally vulnerable machine in an isolated lab network to gain root access.

## Overview
- Built an isolated internal network between Kali and Metasploitable
- Exploited the vsftpd 2.3.4 backdoor for a root shell
- Captured plaintext credentials over Telnet using Wireshark
- Exploited the Samba usermap_script vulnerability via Metasploit

## Tools
Kali Linux, Metasploit, Wireshark
